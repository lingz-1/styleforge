可以，建议你直接把现在这份“**原生 tool-calling + 单 AgentLoop 三套**”方案再往前改一层，最终目标定成：

> **Learn Claude Code / Codex 风格的 Multi-Agent Harness，LangGraph 负责运行时编排；Agent 负责决策，Harness 负责工具、上下文、记忆、Skill、MCP、Hook、权限和生命周期。**

你当前方案里“工具真正注册 + 三套推荐一次运行”这两点保留。
但现在 `AgentLoop.run()` 仍然承担了 tool dispatch、save_candidate、finish gate、stall、状态维护等大量职责。 这部分应该正式拆进 LangGraph。

# 三、Coordinator 不要变成传统 Router

这是一个很重要的边界。

不要重新做：

```python
if "展会" in message:
    goto("research")
elif ...
```

Coordinator 本身也是 LLM Agent，它能：

```text
理解任务
决定是否需要 Research
决定是否需要 Wardrobe Agent
决定是否直接 Stylist
维护全局任务 Plan
处理 Agent handoff
```

例如输出结构化决策：

```json
{
  "goal": "为北京莫里哀音乐剧生成三套穿搭",
  "next_agent": "research",
  "reason": "缺少当前演出时间、地点和主题信息"
}
```

LangGraph只执行这个 handoff。

# 五、CapabilityRegistry 替代 `build_tools()`

当前方案准备在 `agent.py` 中 `build_tools(is_recommend)`。

我建议不要停在这里。

改成真正的：

```text
CapabilityRegistry
```

例如：

```python
registry.register_tool(
    name="search_web",
    description="...",
    input_schema=SearchWebInput,
    handler=search_web,
    tags={"research", "external", "readonly"},
)
```

最终：

```text
CapabilityRegistry
│
├── Local Tools
│   ├── inspect_outfit
│   ├── search_wardrobe

│   ├── search_web

├── Skills
│   ├── event_outfit_planning
│   ├── balletcore
│   └── literary
│
├── MCP
│   └── dynamically discovered tools
│
└── Agents
    ├── research
    ├── stylist
    └── wardrobe
```

然后不同 Agent 获取不同 View：

```python
registry.for_agent("research")
registry.for_agent("stylist")
```

Research 不应该看到 `modify_outfit`。

Critic 也不应该看到 `search_web` 一大堆不相关工具。

# 十、Context Compact 做成 Harness Node

LangGraph：

```text

      ↓
ContextGuard
  ┌───┴────────┐

  │             ↓
  │          Compact
  │             │
  └──────┬──────┘
```

压缩顺序建议：


# 十三、最终 LangGraph State 建议

```python
class StyleForgeState(TypedDict):

    # Request / conversation
    user_id: str
    thread_id: str
    request: str

    goal: str

    status: str

    environment_facts: EnvironmentFacts
```

```python
messages = {
```

## 最后可以把整个新架构概括成

```text
                   LangGraph Runtime
                         │
          ┌──────────────┴──────────────┐
          │                             │
     Multi-Agent Layer             Shared Harness
```
